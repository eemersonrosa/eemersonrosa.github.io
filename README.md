# eemersonrosa.github.io

My cloud resume and project showcase, hosted on GitHub Pages at
**[eemersonrosa.github.io](https://eemersonrosa.github.io/)**.

Based on my [terraform-cloud-resume](https://github.com/eemersonrosa/terraform-cloud-resume)
project (the AWS/Cloudflare version lives at [erosa.net](https://erosa.net)) —
this edition is a static site served straight from this repo.

## What's on it

- Resume (viewable/downloadable PDF)
- About me, skills, and certifications
- Project showcase with links to code and live demos:
  - [Terraform Cloud Resume](https://github.com/eemersonrosa/terraform-cloud-resume) — [live](https://erosa.net)
  - [Terraform Code](https://github.com/eemersonrosa/terraform-code)
  - [The Neon Larks — Band Site](https://github.com/eemersonrosa/emerson-guimaraes-bandsite) — [live](https://eemersonrosa.github.io/emerson-guimaraes-bandsite/)
  - [Ember & Pine Coffee](https://github.com/eemersonrosa/emerson-guimaraes-coffeeshop) — [live](https://eemersonrosa.github.io/emerson-guimaraes-coffeeshop/)

## Stack

Plain HTML/CSS with Bootstrap 4, Font Awesome, and Typed.js. No build step —
GitHub Pages serves the repo root directly.
